# 第一周 Demo 演示脚本

## 演示前准备

- 后端、MySQL、管理后台和微信开发者工具均已启动。
- `database/seed.sql` 已导入。
- 普通用户、第二位用户和管理员账号均可登录。
- 准备一张适合上传的校园图片。

## 演示流程

1. 普通用户登录小程序。
2. 发布“今天在图书馆完成软件工程项目”的图文印记。
3. 选择“学习”标签、“平静”心情和“图书馆”地点。
4. 返回首页，查看刚发布的内容。
5. 使用“软件工程”或“学习”进行搜索。
6. 切换另一位用户，对该印记发表评论。
7. 进入 Web 管理后台，查看新增内容及基础统计。
8. 管理员下架一条预置违规内容。
9. 返回小程序刷新，确认该内容不再公开展示。

## 备用方案

- 保留稳定演示数据，避免现场页面为空。
- 准备一段完整演示录屏，用于处理现场网络或开发工具异常。
- 正式演示版本冻结后不临时增加功能。
