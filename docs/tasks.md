## 完成标准

第一周任务全部完成需要满足：

- 小程序、Spring Boot 后端、MySQL 和 Web 管理后台能够正常运行。
- 普通用户和管理员能够使用真实账号登录。
- 用户能够发布、查看、搜索和评论印记。
- 管理员能够查看并下架内容，且下架内容不再公开展示。
- 核心功能完成自测和前后端联调，API 文档与实际代码一致。
- README、演示账号、演示数据和演示流程准备完成，`main` 分支保存经过验收的稳定版本。
