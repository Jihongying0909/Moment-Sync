# 第一周 Demo 需求范围

## 必须完成

- 普通用户登录、退出和登录状态保存。
- 发布文字与单张图片印记。
- 选择标签、心情和校园地点。
- 首页列表和印记详情。
- 按关键词或单个标签查询印记。
- 发表评论和查看评论。
- 管理员登录、用户列表和内容列表。
- 管理员下架内容。
- 普通用户与管理员权限隔离。
- 初始化演示账号和演示数据。

## 可以简化

- 使用账号密码登录，暂不接微信授权。
- 标签、心情和地点使用预设选项。
- 图片只支持单张上传。
- 后台统计只展示用户、内容和评论总数。
- Agent 只保留入口或原型，不进入本周核心链路。

## 本周不做

- 视频上传、视频摘要和图片理解。
- 圈子、完整好友系统、即时聊天和校园搭子。
- 故事集、时光胶囊和年度报告。
- 复杂同频度算法和真实地图。
- 完整举报审核与大模型安全 Agent。

## 完成标准

- 新环境可以按照 README 启动全部模块。
- 数据库脚本可以完整执行。
- 小程序、后端、数据库和管理后台真实连通。
- 用户能够完成登录、发布、查看、搜索和评论。
- 管理员能够查看并下架内容。
- 下架内容不会继续出现在小程序公开列表中。
- 核心测试通过，无阻断演示的严重缺陷。
