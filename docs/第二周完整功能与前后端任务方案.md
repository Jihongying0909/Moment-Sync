# 拾光同频（Moment Sync）第二周完整功能与前后端任务方案

## 1. 第二周总体目标与功能全景

在第一周 MVP 已跑通「账号登录 → 单图印记发布 → 首页/详情 → 关键词与单标签搜索 → 评论与敏感词拦截 → Web 后台管理与下架」的基础上，第二周目标是**基本完成平台全部核心与特色功能**，实现个人记忆沉淀、校园同频社交、好友即时通讯、智能 Agent 助手与可视化管理后台的完整闭环。

### 1.1 本周需实现的 8 大功能板块

1. **账号、关注与完整好友体系**
   - 普通用户注册（及可选微信授权绑定）、修改登录密码、编辑个人资料（头像、昵称、简介、公开兴趣标签）。
   - 单向关注 / 取消关注、关注列表与粉丝列表。
   - 完整好友关系：发起 / 通过 / 拒绝好友申请、好友列表管理、解除好友。
2. **多媒体印记「发、改、删」与多级可见范围**
   - 支持标题、正文、多张图片（最多 9 张）、短视频（MP4）、**补记历史事件日期**与本地草稿保存。
   - 关联兴趣标签、心情状态、校园地点、公开话题或同频圈子。
   - 支持三档可见范围：**所有人公开（`PUBLIC`）/ 仅关注者或好友可见（`CONNECTIONS`）/ 仅自己可见（`PRIVATE`）**。
   - 支持查看、编辑和删除本人发布的印记。
3. **个人记忆沉淀全套（「拾光」核心）**
   - **四维个人时光轴**：按时间（年/月/日、指定范围、「去年今日」）、标签、心情日历统计、校园足迹卡片多维组织回顾。
   - **记忆故事集 & 好友共同故事集**：将多条印记整理为带封面与简介的故事集，支持邀请好友共同添加维护共享故事集/相册。
   - **时光胶囊**：创建设置未来开启时间的印记（支持图文/视频），未到期前仅展示名称、日期与倒计时，到期自动解锁并发送站内通知。
   - **年度拾光报告**：基于全年记录自动生成总结卡片（发帖/图片/视频数、高频标签、常去地点、最活跃月份、心情分布、收到的互动、年度代表印记与同频伙伴）。
4. **多维组合检索与深度社交互动**
   - **组合检索**：支持按关键词、发布/事件日期范围、标签、心情、校园地点、媒体类型（图文/视频）、发布用户、所属话题/圈子、评分高低进行组合查询。
   - **深度互动**：支持 **1～5 星内容评分**（展示均分、人数与高分排行）、**时光回响**（共鸣 / 温暖 / 有趣 / 加油）与**收藏**、**评论二级回复与删除本人评论**、**内容与评论违规举报**。
5. **兴趣圈层与校园同频社交（「同频」核心）**
   - **首页五维分栏**：关注动态、同频推荐、最新发布、热门内容、圈子动态。
   - **同频话题 & 同频圈子（含圈主角色）**：公开话题聚合页；支持加入/创建兴趣圈子（摄影圈、编程圈、运动圈、志愿服务圈等），**圈子创建者/管理者**可维护圈资料、置顶或移除圈内内容、处理圈内举报。
   - **印记同频度**：仅基于用户主动公开的数据，按加权公式（标签 `0.4` + 圈子 `0.3` + 地点 `0.2` + 互动 `0.1`）计算用户同频度百分比并展示可解释的共同点说明。
   - **时光共振**：系统自动将相近时间、同一校园地点或相似话题下的多条公开印记关联聚合（如“今天有 8 名同学记录了运动场晚霞”）。
   - **双人时光线**：互相关注或好友之间查看共同互动轨迹（首次关注/评论、共同话题/圈子/足迹、互发时光回响）。
   - **校园搭子**：发布自习、跑步、比赛、活动同行等轻量组队招募卡片，支持报名表达兴趣、留言及一键发起沟通。
6. **即时通讯（好友私信 + 拉群聊）与站内通知中心**
   - **好友一对一私信**：好友间实时收发文字、图片与印记分享卡片，维护会话列表与未读计数。
   - **好友拉群聊**：支持勾选多名好友创建群聊（或从校园搭子快速拉群），支持修改群名称、邀请好友入群、群主移出成员/退群及群消息实时广播。
   - **站内消息通知中心**：当收到新关注、好友申请/通过、评论与回复、时光回响、收藏、举报处理结果或时光胶囊到期时生成站内通知并展示未读红点。
7. **「拾光助手」智能 Agent**
   - 提供统一助手入口，通过大模型意图理解与后端工具调用实现：**发布文案润色与标签/圈子推荐**、**自然语言检索历史印记并生成故事集草稿**、**同频伙伴与兴趣圈子推荐**。
   - 严格执行安全闭环：**`Agent 生成建议/草稿 → 用户查看预览 → 用户点击确认 → 系统写入数据库`**。
8. **Web 管理后台完整版与 ECharts 数据大屏**
   - **ECharts 可视化大屏**：展示用户总数与今日活跃、待审核数数字卡，绘制发布趋势折线图、评论与回响趋势折线图、图文视频占比饼图、热门话题/标签柱状图、圈子活跃度排行榜、全站心情分布饼图与举报处理情况柱状图。
   - **全平台治理闭环**：用户查询与禁用/恢复启用、内容多维筛选与下架/恢复上架/删除、评论检索与删除、话题与圈子管理、举报审核流转、动态敏感词库增删管理、管理员关键操作审计日志。

- **Tab 3 `消息`（即时聊天与通知，带总未读红点）**
  - 顶部切换 `聊天会话` ｜ `站内通知`，右上角 `＋ 发起群聊 / 好友申请`。
  - `聊天会话`：展示好友单聊与群聊列表 → 点击进入**聊天对话页**（支持文字/图片/印记卡片，群聊右上角进入**群设置抽屉**改群名、拉人、移人、退群）。
  - `站内通知`：按「互动回响与评分、评论回复、关注与好友、系统与胶囊到期」四类筛选展示，支持一键全部已读。
- **Tab 4 `我的`（个人中心与记忆档案馆）**
  - 顶部扉页名片卡：头像、昵称、简介、公开兴趣标签，右上角「编辑资料 / 账号设置（改密、退出）」，下方 `印记 | 关注 | 粉丝 | 好友` 四宫格计数（点击进列表）。
  - 中部「拾光记忆馆」2×2 卡片入口：**`📅 四维时光轴`**（年月流/去年今日 + 心情日历图 + 校园足迹卡）、**`📖 记忆故事集`**（个人与好友共建故事集）、**`⏳ 时光胶囊`**（倒计时锁信封与已开启列表）、**`✨ 年度拾光报告`**（手账海报翻页卡）。
  - 底部切换：`我的印记`（含编辑/删除/改可见范围）｜`我的收藏与回响`。
- **5 类核心独立二级页**
  1. **登录 / 注册 / 改密页**（居中纸张表单卡）。
  2. **印记发布 / 编辑页**（「✨ 拾光润色」按钮、「普通印记 / 时光胶囊」模式切换、标题正文、9 图网格/MP4 视频选择预览、事件日期选择、标签/心情/地点/圈子选择、可见范围、草稿保存与发布）。
  3. **多维搜索页**（关键词搜索条 + 可展开的多条件组合筛选面板 + 检索结果流）。
  4. **印记详情页**（多图轮播/视频播放器、正文与元信息、1～5 星评分条、4 枚时光回响贴纸 + 收藏 + 举报、支持二级回复与删评的同频留言区）。
  5. **他人主页 & 双人时光线页**（公开资料 + 同频度解释卡 + 公开印记 + 关注/加好友/私信/查看双人时光线）及 **「拾光助手 Agent 对话页」**。

## 4. 后端开发任务清单

### 4.1 数据库平滑扩展（`database/schema.sql` & `seed.sql`）

保持对第一周已有 6 张表的向后兼容，统一使用 `BIGINT` 主键（API 层一律序列化为字符串）：

- **原表兼容扩展**：`user` 表新增 `bio`（简介）；`post` 表新增 `event_date`（事件日期）、`circle_id`（所属圈子）、`rating_avg` / `rating_count`（评分统计冗余）；`comment` 表新增 `parent_id`（父评论 ID，支持二级回复）。
- **新增核心业务表**：
  1. `user_interest_tag`（用户公开兴趣标签关联表）
  2. `user_follow`（单向关注表）与 `friendship` / `friend_request`（好友申请与双向好友表）
  3. `post_rating`（1～5 星评分表，唯一约束防重复刷分）与 `post_reaction`（时光回响及收藏表）
  4. `story_collection`、`story_post`、`story_collaborator`（记忆故事集、所含印记排序及好友共建协作者表）
  5. `time_capsule`（或复用 `post` 增加 `unlock_at` 开启时间字段，服务端严格控制未到期不返回正文与媒体）
  6. `circle`、`circle_member`（同频圈子与成员/圈主角色表）及 `buddy_post`、`buddy_signup`（校园搭子招募与报名表）
  7. `chat_conversation`、`chat_member`、`chat_message`（统一承载好友单聊 `DIRECT` 与群聊 `GROUP` 的会话、成员/群主与消息表）
  8. `notification`（站内通知表）、`content_report`（举报与审核记录表）、`sensitive_word`（动态敏感词表）、`admin_audit_log`（管理员操作日志表）

### 4.2 后端业务与基础设施模块任务

- **账号、关注与好友权限模块（`auth/` & `user/`）**
  - 实现用户注册、修改密码、编辑资料与公开兴趣标签接口；在登录与 JWT 过滤器实时拦截 `DISABLED` 账号。
  - 实现关注/取关、关注/粉丝列表、好友申请发起/审批/删除、好友列表及他人主页查询接口。
  - 抽象统一的可见性判断工具：所有印记查询严格校验 `PUBLIC` / `CONNECTIONS`（作者关注者或好友可见）/ `PRIVATE`（仅本人可见）。

## 5. 「拾光助手」Agent 前后端对接约定

- **职责边界**：外部大模型 API **仅由后端发起调用**；小程序前端只请求自家后端 `/api/agent/*` 接口并负责渲染气泡、快捷指令胶囊与确认卡片。
- **模型选型与环境变量约定（配置与代码解耦）**：
  - 后端统一采用标准 OpenAI 兼容协议（`POST {LLM_BASE_URL}/chat/completions`），通过本地环境变量注入 `LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`，**严禁将真实 `API Key` 提交至 Git 仓库**。
  - **默认开发推荐（完全免费、注册即用）**：智谱开放平台 `GLM-4-Flash`
    - `LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4`
    - `LLM_MODEL=glm-4-flash`
  - **可选替换平台（无需改代码，仅改配置）**：
    - DeepSeek：`LLM_BASE_URL=https://api.deepseek.com`、`LLM_MODEL=deepseek-chat`
    - 阿里云百炼（通义千问）：`LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1`、`LLM_MODEL=qwen-plus`
  - **轻量实现与降级兜底**：采用单轮 JSON 意图与参数提取（无需引入重型框架或流式输出）直接复用项目已有查询 Service；当本地未配置 `LLM_API_KEY` 或外网超时时，自动降级为本地关键词规则匹配查库，确保全组联调与现场演示 100% 可用。
- **核心接口约定**：
  1. `POST /api/agent/polish`（发布辅助）：前端传入草稿标题、正文与已选信息 → 后端返回润色后文本、建议标题、推荐标签/心情/圈子及敏感词预检提示 → 用户在前端点击「采用」后回填表单。
  2. `POST /api/agent/chat`（对话与整理助手）：前端传入自然语言指令 → 后端完成意图拆解与内部工具查询 → 返回 `{ reply, intent, posts, similarUsers, storyDraft }`（**不直接修改数据库**）→ 前端展示预览卡，用户点击「确认创建故事集」或「关注」时，调用标准业务写接口完成落库。
